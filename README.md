# Dada's Little Corner — GitHub Pages

A small static website made with HTML, CSS, and JavaScript. No build tools are required.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — page navigation and note pop-ups
- `content.json` — all 50 notes, the letter, and the final message
- `images/` — the three supplied photos

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository (for example, `dadas-little-corner`).
2. Upload the contents of this folder to the repository's root. Make sure `index.html`, `content.json`, `style.css`, `script.js`, and the `images` folder are at the root level—not inside another nested folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show the published URL in Settings → Pages.

## Privacy note
A public GitHub Pages website can be viewed by anyone with its URL, and a public repository exposes the uploaded source files too. Since this website includes family photos and personal messages, only publish it publicly if you're comfortable with that. GitHub Pages is not a password-protected private website. Avoid including addresses, phone numbers, or other private information.

## Editing later
- To add photos, put them in `images/` and edit the Memories section in `index.html`.
- To change note text, edit `content.json` carefully and keep valid JSON.


Privacy note: This version intentionally contains no personal photos. The memories page uses decorative placeholders instead.
